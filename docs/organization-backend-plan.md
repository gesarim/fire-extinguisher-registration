# Кабинет организации: функции и backend

## Вывод по хостингу

Для обычного виртуального хостинга Beget оптимальный backend: PHP 8 + MySQL.

Если у аккаунта Beget есть VPS/Cloud, можно делать Node.js + MySQL/PostgreSQL. Для текущего прототипа PHP/MySQL проще развернуть на виртуальном хостинге: файлы API кладутся рядом с сайтом, база создается в панели Beget.

## Функции кабинета организации

### Авторизация

- Регистрация организации.
- Выбор роли: организация или подрядчик.
- Отправка одноразового кода на email.
- Проверка кода.
- Создание сессии.
- Вход по email-коду.
- Выход из аккаунта.

### Главная организации

- Загрузка списка объектов организации.
- Переход в объект.
- Загрузка последних проверок.
- Отображение ближайшей предстоящей проверки.

### Сводка организации

- Общее количество огнетушителей.
- Количество огнетушителей в норме.
- Количество требующих проверки.
- Количество неисправных.
- Список проблем по объектам.

### Аккаунт организации

- Просмотр данных компании.
- Добавление сотрудника.
- Удаление сотрудника.
- Приглашение подрядчика.
- Просмотр документов организации.
- Загрузка документов.
- Замена документов.
- Удаление документов.

### Объекты

- Просмотр списка объектов.
- Создание объекта.
- Загрузка документов объекта: договор, ТЗ, план размещения средств ПБ.
- Добавление зданий.
- Добавление помещений.
- Добавление мест расположения огнетушителей.
- Просмотр сводки объекта.
- Просмотр структуры объекта.
- Просмотр проблем объекта.
- Просмотр последних проверок объекта.

### Огнетушители

- Добавление огнетушителя.
- Привязка к объекту, зданию, этажу, помещению и зоне ПБ.
- Номер огнетушителя.
- Фото огнетушителя.
- Статус: в норме, требует проверки, неисправен, снят с эксплуатации.

### Неисправности

- Создание неисправности.
- Привязка к огнетушителю.
- Фото неисправности.
- Отображение в проблемах объекта и общей сводке.

### Проверки

- Запрос проверки.
- Просмотр списка проверок.
- Просмотр деталей проверки.
- Скачивание отчета о проверке.
- Отображение предстоящей проверки.

## Таблицы MySQL

Минимальный набор:

- `users`: пользователи и роли.
- `email_codes`: одноразовые коды входа/регистрации.
- `sessions`: активные сессии.
- `organizations`: организации.
- `organization_members`: сотрудники организации.
- `contractor_invites`: приглашения подрядчиков.
- `documents`: загруженные документы.
- `objects`: объекты организации.
- `buildings`: здания объекта.
- `rooms`: помещения объекта.
- `fire_zones`: зоны ПБ.
- `extinguishers`: огнетушители.
- `issues`: неисправности.
- `inspection_requests`: запросы проверки.
- `inspections`: проведенные/запланированные проверки.
- `inspection_items`: строки проверки.
- `files`: загруженные файлы.

## API кабинета организации

### Auth

- `POST /api/auth/request-code.php`
- `POST /api/auth/verify-code.php`
- `POST /api/auth/logout.php`
- `GET /api/auth/me.php`

### Dashboard

- `GET /api/organization/dashboard.php`
- `GET /api/organization/summary.php`

### Account

- `GET /api/organization/account.php`
- `POST /api/organization/employees.php`
- `DELETE /api/organization/employees.php?id=...`
- `POST /api/organization/contractor-invites.php`
- `POST /api/organization/documents.php`
- `DELETE /api/organization/documents.php?id=...`

### Objects

- `GET /api/organization/objects.php`
- `POST /api/organization/objects.php`
- `GET /api/organization/object.php?id=...`
- `POST /api/organization/object-documents.php`

### Extinguishers

- `POST /api/organization/extinguishers.php`
- `PATCH /api/organization/extinguishers.php?id=...`

### Issues

- `POST /api/organization/issues.php`
- `GET /api/organization/issues.php?objectId=...`

### Inspections

- `POST /api/organization/inspection-requests.php`
- `GET /api/organization/inspections.php`
- `GET /api/organization/inspection.php?id=...`
- `GET /api/organization/inspection-report.php?id=...`

## Порядок внедрения

1. Сделать PHP/MySQL backend и схему БД.
2. Подключить регистрацию и вход по email-коду.
3. Подключить загрузку данных главной организации.
4. Реализовать реальные объекты: список, создание, сводка объекта.
5. Реализовать сотрудников и документы.
6. Реализовать огнетушители и неисправности.
7. Реализовать запросы проверок и отчеты.
8. После этого переходить к кабинету подрядчика.
